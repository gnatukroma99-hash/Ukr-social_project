# Перенос «Поважайте своє» на Rust

Работа идёт в ветке `rust-migration`. Электронная версия, опубликованные APK и код сервера в `main` пока не меняются.

## Уже перенесено

В `crates/svoie-core` работают правила всех пяти аркад и расписание ежедневных квестов. Пять заданий на день, порядок вариантов, очки и серии совпадают с действующей версией. Дату считаем по `Europe/Kyiv` из базы IANA.

JavaScript пока остаётся источником данных. Rust использует те же 99 293 словоформы, 600 цепочек, 720 карточек «Свій / Чужий», 136 слов «Буквопаду» и 96 изображений «Відкрий кадр». Cargo не исполняет JavaScript. Для таблиц в `crates/svoie-core/content/` есть команда `node tools/export-rust-content.mjs`. Запусти её, если меняешь исходные карточки, изображения или тексты квестов в `app/`.

```sh
cargo fetch --locked
cargo test --workspace --locked --offline
rustup target add wasm32-unknown-unknown
cargo check --workspace --locked --offline --target wasm32-unknown-unknown
node tools/export-rust-content.mjs --check
node tools/check-rust-core.mjs
node tools/check-rust-storage.mjs
```

`check-rust-core.mjs` сравнивает обе реализации: все 600 цепочек, ротацию карточек, партии на трёх уровнях, ежедневные колоды и границы суток в Киеве. Данные украинского словаря сохраняют лицензию [MPL-1.1](../app/assets/licenses/uk-hunspell.txt).

`crates/svoie-client` читает тестовые данные по ключам `svoie.v1`, `svoie.arcade.v2` и `svoie.appearance.v1`. Rust восстанавливает закладки, очки офлайн-квестов, тему, рекорды и незавершённое «Вгадай слово». Рекорды, сделанные до выбора сложности, попадают в «Середньо». Модуль не открывает профиль установленного приложения и не переносит токены.

## Локальное превью

Для превью нужны Node.js, цель Rust `wasm32-unknown-unknown` и [wasm-bindgen-cli 0.2.130](https://github.com/wasm-bindgen/wasm-bindgen/releases/tag/0.2.130) в `PATH` (или укажи путь в `WASM_BINDGEN`).

```sh
npm ci --ignore-scripts
node tools/build-rust-preview.mjs
node tools/check-rust-preview.mjs
python -m http.server 8765 --bind 127.0.0.1 --directory target/svoie-preview
```

Открой `http://127.0.0.1:8765`. На этом адресе есть отдельные сохранения. На тех же экранах WebAssembly проверяет слова, подбирает подсказки в цепочках, считает дату и баллы офлайн-квестов и читает сохранения аркады. Если браузер не запускает WebAssembly, остаются правила JavaScript. Превью не входит в APK и ZIP и не обращается к API турнира.

## Следующие этапы

1. Подключить хранилище к клиенту, проверить запись и обновление установленных версий Android и Windows. Не менять ключи, пока обе проверки не пройдены.
2. Подключить Rust к клиенту и перенести экраны. Сначала проверить оболочку на Android 6/API 23, прежде чем заменять Capacitor. Сохранить украинский текст, CSS, обложки PhotoCraft и офлайн-режим. HTML/CSS и манифесты платформ останутся.
3. Перенести сервер на Axum. Проверить API со старой версией клиента на синтетических данных и на резервной копии SQLite. Сохранить адрес Railway, настройку Google через Supabase, формат токенов и путь `/auth/finish`. Не менять рабочий турнир, пока не подтверждены вход на двух устройствах, результаты и итоговый рейтинг.

## Перед заменой установленных версий

- Android: проверить установку поверх предыдущего APK с тем же `ua.povazhaite.svoie` и тем же сертификатом подписи, с увеличенным `versionCode`. Для Google Play использовать отдельный upload key. Сверить поддержку устройств с нынешним минимумом Android 6/API 23: у Tauri 2 по умолчанию API 24.
- Если сменится адрес WebView на Android или каталог профиля на Windows, прежний `localStorage` автоматически не перенесётся. До выпуска проверить перенос локальных квестов, закладок, рекордов и темы. Не переносить секреты через экспорт закладок. Для проверки входа можно запросить повторную авторизацию.
